# ECE2.414 Advanced Memory Circuits and Systems

## Assignment 1

This repository contains the simulation files, configurations, scripts, and results for Assignment 1.

### Parts

- **Part A:** SRAM bitcell analysis using ngspice
- **Part B:** SRAM cache analysis using CACTI
- **Part C:** STT-MRAM cache analysis using NVSim
- **Part D:** DRAM analysis using Ramulator 2.0
- **Part E:** Performance evaluation using gem5

### Tools

- ngspice
- CACTI
- NVSim
- Ramulator 2.0
- gem5
